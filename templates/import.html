What it expects

The same shape the Export CSV button produces. Required columns are date, exercise and reps; split, muscle_group, set_number, weight_kg and session_notes are used when present. 

date,user,split,muscle_group,exercise,set_number,weight_kg,reps,session_notes
2026-08-20,Dario,Push,Chest,Bench,1,60,8,felt strong
2026-08-20,Dario,Push,Chest,Bench,2,62.5,6,

Everything is imported into {{ user_name }}'s history, whatever the user column says. Splits and exercises named in the file are created if they don't exist yet. A set that's already there — same date, exercise and set number — is skipped, so importing the same file twice doesn't duplicate anything. An empty weight_kg means a bodyweight set.
